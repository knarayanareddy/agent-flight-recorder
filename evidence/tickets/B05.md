# B05 Jobs/Outbox — replay worker integration tests (written; gated on PostgreSQL 16)

## Status: tests written; skipped locally (no PostgreSQL 16 available)

### What was delivered

- `src/worker/replay_worker.py` — fenced lease replay worker (committed in B06 core):
  - `SKIP LOCKED` claim of `queued` `afr.replay` jobs ordered by `created_at, id`
  - Lease fence incremented on claim; `lease_until` set 30s ahead
  - `compute_replay_result` (read-only, fail-closed: zero network calls, no live
    fallback) + `finalize_replay` (fenced terminal job transition; rejects stale
    fences, never treats a stale completion as success)
  - Outbox delivery mark (`afr.replay.requested`) after successful finalize
  - Cancellation-safe: cancelled jobs stay terminal, never overwritten
- `src/worker/main.py` — worker entry point (`WORKER_PROJECT_SCOPES` env, SIGTERM/
  SIGINT handling)
- `tests/worker/test_replay_worker_integration.py` — 4 gated integration tests:
  1. `test_worker_claims_queued_job_and_leases` — claims a queued job, verifies
     lease state/fence/lease_until on the real `core.jobs` row
  2. `test_worker_fenced_completion_rejects_stale_fence` — correct fence -> terminal
     + replay result; same-claim re-process -> 'stale'; advanced fence -> 'stale'
  3. `test_worker_cancelled_job_stays_terminal` — cancelled job not claimed; stale
     claim on cancelled job -> 'gone'; job state unchanged
  4. `test_worker_end_to_end_replay_with_artifact` — full claim+compute+finalize
     flow with a ready recording artifact; verifies job terminal, replay result
     persisted (`pass`, 0 network calls, check matched), outbox delivery marked
