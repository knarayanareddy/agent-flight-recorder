# B03 Identity/Authorization — auth/OIDC stubs (slice complete, full acceptance pending)

## Status: stubs implemented; production fail-closed preserved

### What was delivered

- `src/core/oidc.py` — local test OIDC IdP stub (`OidcStubProvider`) issuing signed,
  JWT-like stub tokens using only the Python standard library (no PyJWT/cryptography
  dependency added). Verify token issuer, expiry, signature; reject tampered/unknown-issuer/
  expired/malformed tokens. Test-only; never used by production runtime.
- `src/core/security.py` — `verify_token()` now delegates to an optionally configured
  OIDC verifier (lazy import, no circular dependency). With no verifier configured
  (production default), it returns `None` for every token: fail-closed, static test
  tokens never accepted.
- `src/core/oidc.configure_oidc_verifier()` / `verify_token_via_oidc()` — test-only
  injection point. Production never calls it.
- `tests/conftest.py` — added `oidc_stub_provider` and `oidc_verifier` fixtures
  (configure/unconfigure guarantees the global verifier resets to `None` after each
  test, so fail-closed behavior is not leaked between tests).
- `tests/test_oidc_stub.py` — 9 tests: issue/verify, tampered rejection, unknown
  issuer, expiry, malformed tokens, production fail-closed, configure/delegate,
  verify-token reset-after-test, issuer constant is test-only.

### What remains (not claimed complete)

- Real OIDC login/logout/expiry/state/PKCE/CSRF flow against a live IdP — requires
  B03 acceptance review and a configured OIDC issuer; not implemented here.
- Capability matrix, API-key scopes, 401-first endpoint smoke against a real database
  — blocked without PostgreSQL 16 (see B05 blocking note).
- These require independent evidence review; not self-certified.

### Constraints honored

- No default credentials; no production keys; `TEST_ISSUER = http://test-idp.local/oidc`

- Synthetic identities injected exclusively via test dependency overrides; normal
  runtime rejects static test tokens (`verify_token` returns None).
